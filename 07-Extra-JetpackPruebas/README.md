# JetPackPruebas

Este proyecto es una aplicación de práctica desarrollada con lo aprendido en el curso **"Android con Kotlin"** de **Píldoras Informáticas**. 

Su objetivo principal es experimentar y aprender las bases de **Jetpack Compose**, el kit de herramientas moderno de Android para construir interfaces de usuario nativas.

## 🚀 Características actuales

El proyecto cuenta con las siguientes funcionalidades e implementaciones:

*   **Pantalla de Login:** Una interfaz sencilla con campos de texto para correo electrónico y contraseña.
*   **Componentes de Compose:** Uso de `Scaffold`, `Box`, `Column`, `TextField`, `Button`, `Surface` y `Text`.
*   **Gestión de Estado:** Implementación de `remember` y `mutableStateOf` para el manejo de la entrada de datos del usuario.
*   **Interacción:** Uso de `Toast` para mostrar mensajes al usuario al interactuar con el botón de inicio de sesión.
*   **Diseño Adaptativo:** Implementación de `enableEdgeToEdge()` para aprovechar todo el espacio de la pantalla.
*   **Composables personalizados:** Ejemplos de organización de código mediante funciones Composable (`Formulario`, `LayoutPrincipal`, `Bandera`).

## 🛠️ Tecnologías utilizadas

*   **Lenguaje:** Kotlin
*   **UI Framework:** Jetpack Compose
*   **Arquitectura:** Siguiendo los principios básicos recomendados para Compose.
*   **Material Design 3:** Uso de los componentes y temas de Material 3.

## ⚙️ Cómo ejecutar el proyecto

1.  Clonar el repositorio o descargar el código fuente.
2.  Abrir el proyecto en **Android Studio** (versión recomendada: Jellyfish o superior).
3.  Sincronizar el proyecto con los archivos Gradle.
4.  Ejecutar en un emulador o dispositivo físico con Android 5.0 (API 21) o superior.
