## ¿Qué es Kotlin?

**Kotlin** es un lenguaje de programación moderno, conciso y seguro, desarrollado por JetBrains. Es 100% interoperable con Java y desde 2019 es el **lenguaje oficial recomendado por Google** para el desarrollo de aplicaciones Android. Combina lo mejor de la programación orientada a objetos y funcional en un solo lenguaje.

### ¿Por qué usar Kotlin para Android?

- **Conciso y expresivo** — Menos código boilerplate que Java. Una misma funcionalidad requiere hasta un 40% menos de líneas.
- **Null Safety** — El sistema de tipos de Kotlin elimina los temidos `NullPointerException` al compilar, haciendo el código más seguro y predecible.
- **Interoperable con Java** — Puedes usar librerías Java existentes y migrar progresivamente sin reescribir todo.
- **Moderno y funcional** — Soporta lambdas, funciones de orden superior, `data class`, `sealed class`, corrutinas y más.
- **Oficial para Android** — Google lo adoptó como lenguaje oficial en 2019. La mayoría de las nuevas APIs, librerías y herramientas de Android están optimizadas para Kotlin.
- **Jetpack Compose** — El toolkit moderno de UI declarativa para Android está diseñado nativamente para Kotlin, aprovechando sus características como lambdas, `@Composable` y `State`.

## Descripción del Proyecto

Este repositorio contiene los proyectos desarrollados durante el curso de **Android con Kotlin** de [Píldoras Informáticas](https://www.youtube.com/playlist?list=PLU8oAlHdN5BkdfBPpNv_lVCJxJgE87cr0). A lo largo del curso se recorren los fundamentos del lenguaje Kotlin, la programación orientada a objetos, el desarrollo de aplicaciones Android con XML (Views) y finalmente la UI declarativa moderna con Jetpack Compose.
